5.  Which bit of the Ethernet address is used to determine whether it is 
unicast or multicast/broadcast? Also, what values of this bit correspond to unicast or 
multicast/broadcast?

The first byte of the address' least significant bit determines if it is
unicast or multicast. You can say it depends on if the first byte is even or
odd. If the LSB is 0 then it is unicast if it is 1 it is multicast. Usually in hex 
multicast uses 01 as the first byte and unicast uses 80 or 3c. For broadcast,
the address is all 1's. So, the address is ff ff ff ff ff ff which also
satisfies the LSB being 1 to be a multicast.
